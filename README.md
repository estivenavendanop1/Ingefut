# Mi Página de Fútbol - Proyecto de Desarrollo Web

Página sencilla hecha con HTML, CSS y JavaScript.

## Estructura de carpetas
```
proyecto_web/
├── index.html          (inicio)
├── paginas/            (equipos, multimedia, contacto)
├── css/estilos.css     (estilos)
├── js/script.js        (contador de goles)
├── img/                (imágenes y favicon)
└── multimedia/         (video y audio)
```

## Requerimientos cumplidos
- Rutas relativas
- Directorios organizados
- Etiquetas semánticas (header, nav, main, section, footer)
- Repositorio Git
- No se mezclan lenguajes (HTML, CSS y JS por separado)
- Favicon
- Responsive (se adapta al celular)
- Multimedia (imágenes, video y audio)
- Navegación entre 4 páginas
- Tablas, listas y formularios
- CSS
- Funcionalidad con JS (contador de goles)
