# Café Aroma - Proyecto de Desarrollo Web

Página web sencilla hecha con HTML, CSS y JavaScript.

## Estructura de carpetas
```
proyecto_web/
├── index.html          (página de inicio)
├── paginas/            (otras páginas: productos, multimedia, contacto)
├── css/estilos.css     (estilos)
├── js/script.js        (funcionalidad con JavaScript)
├── img/                (imágenes y favicon)
└── multimedia/         (video y audio)
```

## Requerimientos cumplidos
- Rutas relativas
- Directorios organizados
- Etiquetas semánticas (header, nav, main, section, article, footer)
- Repositorio Git
- No se mezclan lenguajes (HTML, CSS y JS en archivos separados)
- Favicon
- Responsive (se adapta al celular)
- Multimedia (imágenes, video y audio)
- Navegación entre 4 páginas
- Tablas, listas y formularios
- CSS
- Funcionalidad con JS (modo oscuro, fecha y mensaje al enviar el formulario)
